# Повторное использование возвращаемых значений

Указатель: использование модулей с повторным использованием возвращаемых значений, std 724. Флаги модуля брать из XML общего модуля или карточки объекта MCP, не по памяти. Правило про флаг на изменяемых данных — в [standards.md](standards.md), здесь не дублировать.

### Параметры и результат кэшируемой функции

Когда ставить: в общем модуле с повторным использованием экспортная функция принимает параметр не простого типа и не ссылки (структура, таблица значений, объект). Либо модуль на время сеанса возвращает объект базы, запрос, менеджер временных таблиц или коллекцию с такими значениями.

Не ставить: параметры простых типов (число, строка, дата, булево, `Неопределено`, `NULL`) и ссылки. Повторное использование «на время вызова» для ограничения по результату: оно относится к модулям «на время сеанса». Сигнатура или флаг модуля не видны — «не хватает факта».

Как доказать: флаг повторного использования модуля из карточки объекта, сигнатура экспортной функции и тип параметра или возвращаемого значения.

Тяжесть: важно. Критично, если кэшируемое значение возвращает изменяемый объект, который затем меняют, и это видно в коде.

# Что не копировать своим регистром

Имя подсистемы сверять с выгрузкой. Нет подсистемы — нет требования её внедрить. Есть подсистема, а рядом свой регистр на ту же задачу — смотреть правило «Определяемый тип и подписка» в [bsp.md](bsp.md).

Имена в таблице — ориентир по смыслу задачи, а не гарантированные имена объектов: у разных релизов БСП и разных конфигураций они отличаются (и в EDT, и в XML подсистема может называться иначе). Проверять по своей выгрузке или карточке объекта; имя не подтверждено — писать «подсистема на эту задачу, точное имя не подтверждено», а не требовать внедрить конкретную.

| Задача в коде | Куда смотреть сначала |
|---|---|
| Сообщения пользователю, журнал регистрации, общие вызовы | Базовая функциональность, `ОбщегоНазначения` |
| Текущий пользователь и роли | Пользователи |
| Профили и ограничение на записях | Управление доступом |
| Смена версии конфигурации | Обновление версии ИБ |
| Команда печати и макет | Печать |
| Внешняя обработка без снятия с поддержки | Дополнительные отчёты и обработки |
| Реквизит без нового метаданного на каждый случай | Свойства |
| Адрес, телефон, почта | Контактная информация |
| Файл у справочника или документа | Присоединенные файлы |
| История версий объекта | Версионирование объектов |
| Запрет записи задним числом | Дата запрета изменения |
| Префикс номера | Префиксация объектов |
| Фоновое задание | Регламентные и фоновые задания |
| Регистрация изменений | Обмен данными |
| Скачивание по HTTP | Получение файлов из интернета |
| Запрет правки ключевых реквизитов | Запрет редактирования реквизитов объектов |
| Связанные документы | Структура подчинённости |
| Дубли | Поиск и удаление дублей |
| Варианты отчёта | Варианты отчётов |

Своя подсистема законна, если в таблице нет строки или поведение нельзя получить переопределяемым модулем. В замечании назвать строку, которую проверили. Не названа строка — замечание не открывать.

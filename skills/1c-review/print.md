# Печатные формы

Указатели: формирование печатных форм, std 548 (диагностика ACC 384); печатные формы с учётом правки макета пользователем, std 789. Текст стандартов не цитировать. Код печатной формы читать из присланного модуля; макета в diff может не быть — тогда то, что зависит от макета, «не хватает факта».

### Область макета без проверки

Когда ставить: код печатной формы получает область макета через `Макет.ПолучитьОбласть("Имя")` (или обращается к `Макет.Области` по имени) без предшествующей проверки, что такая область в макете есть, а пользователь может править макет печатной формы.

Не ставить: перед получением области есть поиск среди областей макета (`Макет.Области.Найти(...)`) и обработка отсутствия. Макет закрыт от пользовательской правки (регламентированная форма, правка отключена средствами подсистемы управления печатью БСП). Область обязательна по смыслу формы и её отсутствие намеренно приводит к ошибке с понятным сообщением. Макет и способ его подключения не видны — «не хватает факта», запрет не ставить.

Как доказать: вызов `ПолучитьОбласть` с литералом или переменной имени и отсутствие проверки существования области выше по процедуре.

Тяжесть: важно.

### Явное присвоение параметров области

Когда ставить: параметры области заполняются присвоением по одному (`Область.Параметры.Имя = Значение`) в печатной форме с пользовательским макетом: если пользователь удалит параметр, код упадёт.

Не ставить: параметры заполняются массово через `ЗаполнитьЗначенияСвойств` (отсутствующие свойства игнорируются). Макет закрыт от правки. Присвоено единственное обязательное свойство, без которого форма не имеет смысла, и это видно по комментарию или проверке выше. Тип макета не виден — «не хватает факта».

Как доказать: присвоения свойств `Параметры` области и отсутствие массового заполнения.

Тяжесть: важно.

### Нулевые поля табличного документа

Когда ставить: у табличного документа печатной формы `ПолеСверху`, `ПолеСлева`, `ПолеСнизу` или `ПолеСправа` устанавливается в `0`: текст у края может обрезаться принтером.

Не ставить: ненулевые значения, стандартные или регламентированные для формы. Значение приходит из переменной, число которой в присланном фрагменте не видно — «не хватает факта».

Как доказать: присвоение нулевого значения свойству поля табличного документа.

Тяжесть: важно.

### Запрос на каждый объект при печати нескольких

Когда ставить: процедура печати принимает массив объектов и внутри цикла по ним выполняет запрос (`Запрос.Выполнить()` в теле итерации), хотя данные можно выбрать одним запросом по массиву.

Не ставить: один запрос по массиву ссылок до цикла, цикл обходит результат. Следующая итерация зависит от данных предыдущей, и пакет собрать нельзя. Тело вызываемой функции печати не видно, а в цикле только вызов — «отдать человеку» или «не хватает факта». Общее правило про запрос в цикле — [queries.md](queries.md), здесь не дублировать.

Как доказать: цикл по массиву объектов, `Выполнить()` в его теле и поля, известные до цикла.

Тяжесть: важно.

### Порядок строк в печатной форме

Когда ставить: запрос табличной части для печатной формы без `УПОРЯДОЧИТЬ ПО` номеру строки или другому полю: порядок строк на разных СУБД может отличаться от экранной формы.

Не ставить: ТЧ читается из объекта в порядке хранения, без запроса. Сортировка есть. Запрос агрегирует данные и порядок задан отдельной сортировкой в результате. Текст запроса целиком не виден — «не хватает факта».

Как доказать: текст запроса по табличной части без `УПОРЯДОЧИТЬ ПО`, результат которого выводится в печатную форму.

Тяжесть: важно.

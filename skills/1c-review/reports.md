# СКД, отчёты и динамические списки

Указатели: запросы в динамических списках, std 732; применение параметров отчёта в СКД, std 407. Текст стандартов не цитировать. Требования к запросу динамического списка строже, чем к отчёту или обработке данных: список виден пользователю напрямую. Схема компоновки и настройки целиком в diff есть не всегда.

### Тяжёлая конструкция в запросе динамического списка

Когда ставить: в тексте запроса динамического списка есть `РАЗЛИЧНЫЕ`, `СГРУППИРОВАТЬ ПО`, `ВЫБОР` в `ГДЕ` или в условии соединения, сортировка по полю, вычисляемому `ВЫБОР`, соединение с вложенным запросом, либо соединение с виртуальной таблицей в стандартном режиме списка.

Не ставить: запрос не динамического списка (отчёт, обработка, программный запрос из модуля): для них такого запрета нет. Соединение с `СрезПоследних` или `СрезПервых` при небольшом объёме данных допустимо; объём не виден — «не хватает факта». Временная таблица заведомо с небольшим числом записей. Число соединённых таблиц (порядка четырёх) только ориентир, само по себе нарушением не считать. Не видно, что запрос назначен именно динамическому списку, — «не хватает факта».

Как доказать: свойство динамического списка (основная таблица, текст запроса) и конструкция в этом тексте. Запрос только из модуля формы без отметки о списке — «не хватает факта».

Тяжесть: важно.

### Обязательный параметр вместо отбора

Когда ставить: в запросе схемы компоновки простое условие по полю записано как `ГДЕ Поле = &Параметр` вне фигурных скобок, и пользователь должен иметь возможность отключить это условие в настройках отчёта: отключение даёт ошибку «Не задан параметр отчёта». Условие по периоду без `{ГДЕ ...}` — тот же случай.

Не ставить: параметр обязателен по смыслу (дата, на которую считаются остатки, параметр виртуальной таблицы), и без него запрос не имеет результата. Отчёт без пользовательских настроек. Условие уже обёрнуто в фигурные скобки. Настройки параметра (доступность пользователю, выражение) из присланного фрагмента не видны — «не хватает факта».

Как доказать: фрагмент текста запроса с условием по параметру без фигурных скобок и признак, что пользователь отключает условие в настройках.

Тяжесть: мелочь.

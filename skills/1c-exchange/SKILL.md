# Обмен и HTTP

Предмет — модули обмена, HTTP-вызовы и проведение, связанное с пакетом, в diff или явно присланном фрагменте. Четыре класса: **нарушение**, **законный случай**, **не хватает факта**, **отдать человеку**. Юрисдикция diff: нет регистра журнала или объекта интеграции в выгрузке — не выдумывать имя регистра и не советовать «запишите сюда».

## Когда открывать

- HTTP, почта, файловый вызов рядом с транзакцией или в `ОбработкаПроведения`.
- Повтор входящего пакета, внешний идентификатор, постраничная загрузка.
- Роутер направил по «обмен», «интеграция», «пакет».

Отдельно от «просто проведение без внешнего вызова» — если в diff только внутренняя логика без HTTP, карточки обмена не раздувать.

## Шаги по порядку

1. **Область.** Процедуры приёма/отправки, проведение документов обмена, границы транзакций в diff.
2. **Карточки.** Повтор пакета, внешний вызов и транзакция, страница, статус — [../1c-review/exchange.md](../1c-review/exchange.md). Куда класть код, чтобы не затёрло обновление — [../1c-review/extension.md](../1c-review/extension.md), без заявлений о поддержке без выгрузки поставщика.
3. **Связка с проведением.** HTTP (или иной внешний вызов) между `НачатьТранзакцию` и фиксацией либо внутри проведения до окончания записи движений — класс **нарушение**, тяжесть **критично**; сразу эскалировать в `1c-review` как блокирующее для вердикта **править**.
4. **Классификация.** Остальные срабатывания — по карточкам с доказательством из кода. Журнала курсора нет во фрагменте — **не хватает факта**, не придумывать регистр.
5. **Передача.** Классы, цитаты, контуры — в `1c-review` для сводки и вердикта.

## Стоп и запреты

- Не писать сводку и вердикт — только `1c-review`.
- Не называть регистры и методы площадки, которых нет в выгрузке или присланном модуле.
- Не смягчать HTTP в проведении до «важно», если карточка «Внешний вызов и транзакция» доказана в diff.
- Не судить типовую на поддержке без выгрузки — граница в [exchange.md](../1c-review/exchange.md).

## Что отдать review и человеку

- **1c-review:** список срабатываний exchange.md, отдельно пометить критичное HTTP в проведении для вердикта **править**; «не хватает факта» по журналу/курсору.
- **Человеку:** один вопрос, если без журнала обмена или статусов площадки класс не закрывается — без выдуманных имён объектов.

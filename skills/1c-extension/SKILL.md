# Расширение (CFE)

Предмет — файлы расширения и связанные фрагменты основной конфигурации в diff. Четыре класса: **нарушение**, **законный случай**, **не хватает факта**, **отдать человеку**. Юрисдикция diff: нет каталога CFE, второй выгрузки поставщика или признака замка в присланных файлах — не выводить «на поддержке» / «снят» / «цепочка цела».

## Когда открывать

- В diff каталог расширения, `cfe`, аннотации `&Перед`, `&После`, `&Вместо`, заимствование модулей.
- Вопрос, переживёт ли правка обновление поставщика или не сломает типовое проведение.
- Роутер направил по фразам «расширение», «CFE», «&Вместо».

Не открывать для чисто косметики синонима вне расширения — это не вход в extension-процесс.

## Шаги по порядку

1. **Область.** Какие объекты в diff: перехваты, заимствованные модули, правки основной конфигурации. Вне diff — не судить.
2. **Две выгрузки.** Для сравнения сигнатуры с поставщиком и чужого перехвата нужны обе выгрузки. Есть только dump основной без CFE — единственный допустимый итог по цепочке: **не хватает факта**, без «нарушение» и без «можно сдавать».
3. **Карточки.** Правила по аннотациям, заимствованию, двойному поведению и правке основной — [../1c-review/extension.md](../1c-review/extension.md). Роли `ПолныеПрава` — [../1c-review/standards.md](../1c-review/standards.md). Порядок двух расширений в базе — [../1c-review/handoff.md](../1c-review/handoff.md).
4. **Классификация.** На каждое срабатывание карточки — один из четырёх классов с доказательством из diff.
5. **Передача.** Итог классификации и пробелы фактов — в `1c-review` для сводки и вердикта. «Отдать человеку» — когда замок, шаблон ограничения или порядок расширений решает контур, которого в выгрузке нет.

## Стоп и запреты

- Не писать «разошлась сигнатура» или «чужой перехват сломан» без второй выгрузки владельца процедуры.
- Не объявлять объект «на поддержке» или «снят» по одному пути файла — см. карточку «Правка основной конфигурации» в [extension.md](../1c-review/extension.md).
- Не писать сводку и вердикт сдачи — только `1c-review`.
- `&Вместо` без продолжения на проведении, движениях или обмене — **нарушение**, не закрывать молчанием.

## Что отдать review и человеку

- **1c-review:** перечень перехватов, классы по [extension.md](../1c-review/extension.md), явные «не хватает факта» (нет CFE, нет dump поставщика, нет файла поддержки в diff).
- **Человеку:** запрос второй выгрузки, подтверждение снятия с поддержки или решение по порядку расширений — одной фразой, без списка замечаний на каждую строку.

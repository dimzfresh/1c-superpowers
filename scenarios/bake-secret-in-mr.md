# Сценарий bake: секрет в diff / комментарий MR

**Фикстура.** `tests/fixture-secrets/FormModule.bsl` — строковый литерал пароля и передача в `HTTPСоединение`.

**Вход.** `1c-review` + [secrets.md](../skills/1c-review/secrets.md). Просьба: «проверь модуль» / «ревью перед MR».

**Ожидание.**

- Класс **нарушение**, тяжесть **критично**: в diff лежит значение пароля/токена.
- В замечании и в любом тексте для MR/чата — **значение литерала не копировать**. Только путь файла, имя реквизита/параметра, факт «в коде секрет».
- Вердикт: **править** (убрать литерал: хранилище, параметр сеанса, секретница).
- Учебный хост `api.example.com` сам по себе не секрет; секрет — литерал пароля.

# Сценарий: «не проводится» без ЖР

**Вход.** Автор: «документ не проводится, почини». Текста ошибки, стека ЖР и фрагмента модуля проведения нет — только имя документа.

**Юрисдикция diff.** Без присланного модуля, стека или записи ЖР причину проведения не reconstructить.

**Ожидание (1c-systematic-debugging).**

- **Симптом** отделить от интерпретации; собрать **факты**: текст ошибки, стек, строка модуля, транзакция/блокировка из ЖР — что реально приложено.
- **Гипотез** формулировать только от **факта**; без факта — стоп и один запрос данных, не «перепиши модуль наугад».
- Проверка гипотезы — минимальный эксперимент (точечная правка, повтор проведения, один прогон теста), не замена всего модуля.
- Сводку и вердикт сдачи не писать — перед MR **1c-verification** и **1c-review**.

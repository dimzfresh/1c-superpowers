# Сценарий: &Вместо без выгрузки CFE

**Вход.** В diff основной конфигурации виден вызов перехваченного проведения; автор спрашивает, сломает ли `&Вместо` типовой сценарий. Приложена только выгрузка основной конфигурации, каталога расширения (CFE) нет.

**Юрисдикция diff.** Без файлов расширения в diff или отдельной выгрузки CFE цепочку перехвата не доказывать.

**Ожидание (1c-extension → 1c-review).**

- Единственный корректный класс по цепочке: **не хватает факта** (нет второй выгрузки / модулей CFE).
- Не писать «нарушение», «законный случай» и не «можно сдавать».
- В резюме review — одна фраза, чего не видно; вердикт с оговоркой по факту, не **править** без доказательства.

# Сценарий bake: основная без CFE

**Вход.** Автор просит оценить `&Вместо` на проведении. В diff / выгрузке — только основная конфигурация. Каталога расширения (CFE) и модулей с аннотациями нет.

**Юрисдикция.** Цепочку перехвата, продолжение и «чужой» `&Вместо` без файлов CFE не восстанавливать.

**Ожидание (1c-extension → передача в 1c-review).**

- Класс: **не хватает факта** (нет второй выгрузки / модулей расширения).
- Не ставить **нарушение** «нет продолжения» и не объявлять **законный случай**.
- Вердикт **править** по цепочке CFE — запрещён без доказательства в файлах.
- В резюме — одна фраза: чего не видно (CFE / аннотации). Допустимо «сдать с оговоркой» только если остальной diff это допускает; цепочку расширения не закрывать молчанием.

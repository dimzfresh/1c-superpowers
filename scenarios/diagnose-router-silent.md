## Ожидаемый разбор diagnosing

| Улика (цитата) | Пропущенный скилл | Что открыть сейчас |
|---|---|---|
| Ответ с BSL сразу на «сделай» | `using-1c-superpowers` → `1c-brainstorming` / `1c-writing-plans` | Сначала роутер и границы diff |
| HTTP в проведении без review | `1c-exchange` / `1c-review` | Ревью проведения |
| «Готово, замечаний нет» без фактов | `1c-verification` | Шлагбаум «проверено» |
| Нет сводки с вердиктом | `1c-review` | Единственная дверь сводки |

**Главный пропуск:** не открыт `using-1c-superpowers` — ответ «из головы».

**Следующее сообщение пользователю:** открыть роутер, затем `1c-review` на этот фрагмент (ожидаемо **править** по HTTP в проведении).

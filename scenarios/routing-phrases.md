# Маршрутизация

- сделай обработку → `1c-brainstorming`
- разложи на задачи → `1c-writing-plans`
- по плану давай код → `1c-executing-plans`
- напиши тест сначала → `1c-tdd`
- не проводится / ЖР → `1c-systematic-debugging`
- тормозит / долго проводится / таймаут блокировки → `1c-performance`
- проверено / можно сдавать → `1c-verification`
- ревью MR / diff → `1c-review`
- пришли замечания с ревью → `1c-receiving-review`
- закрой ветку / MR готов → `1c-finish-branch`
- расширение / &Вместо → `1c-extension`
- обновление поставщика → `1c-update`
- HTTP / пакет обмена → `1c-exchange`
- новая карточка / правило ревью → `1c-writing-skills`
- скилл молчал / сессия поехала → `diagnosing-1c-superpowers`

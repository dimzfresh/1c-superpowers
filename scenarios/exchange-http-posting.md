# Сценарий: HTTP внутри проведения

**Вход.** В diff модуль документа, `ОбработкаПроведения`: после `НачатьТранзакцию` и до записи движений — вызов HTTP к внешней площадке. Пакет обмена в том же diff не разбирали.

**Юрисдикция diff.** Суждение только по показанному фрагменту проведения; регистры журнала обмена не выдумывать.

**Ожидание (1c-exchange → 1c-review).**

- Класс **нарушение** по [exchange.md](../skills/1c-review/exchange.md) («Внешний вызов и транзакция»), тяжесть **критично**.
- Вердикт review: **править** (блокирующее для сдачи).
- Сводку и список замечаний оформляет **1c-review**, не verify и не exchange-скилл.

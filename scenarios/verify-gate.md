# Сценарий: «проверено» при одном синтаксисе

**Вход.** Автор: «проверено, можно в MR». В diff один общий модуль. BSL Language Server без ошибок. Данных конфигурации (режим совместимости, БСП) и хвоста прогона `find_checks` в сообщении нет.

**Юрисдикция.** Смотреть только присланный diff и явные артефакты verify; платформу и БСП из головы не собирать.

**Ожидание (1c-verification → 1c-review).**

- Если diff версионно-зависимых карточек не касается, данные конфигурации не требовать; «проверено» допустимо только с названной областью («в пределах присланного diff»). Если касается — класс **не хватает факта** по режиму совместимости и БСП, голое «проверено» не подтверждать.
- **Синтаксис** — второй контур: зелёный LS не заменяет ревью проведения, прав и обмена.
- Сводку и вердикт формирует только **1c-review** (обычно «сдать с оговоркой» или «не хватает факта» в резюме, не «можно сдавать»).

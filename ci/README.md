# CI для проектов на 1С

`gitlab-ci-1c.yml` — шаблон для MR: BSL Language Server (результат в JUnit) и карта проверок `find_checks.py`.

Что здесь нет намеренно: запуска ИИ-ревью в CI и публикации вердикта. Вердикт набора зависит от фактов о конфигурации и не должен выдаваться без человека; сводку `1c-review` публикуют по просьбе, один раз, с меткой `<!-- 1c-review -->` (`skills/1c-review/repo.md`).

Версию BSL LS и имя артефакта сверяйте с релизами `1c-syntax/bsl-language-server`: они менялись между релизами. Команда запуска (`--analyze --srcDir … --reporter junit`) описана в документации проекта.

Проверка общего модуля НастройкиПовтИсп (Server=true, ServerCall=false, Privileged=false, ReturnValuesReuse=DuringSession)

Главная проблема: устаревшее значение настройки из-за кэширования на время сеанса.

Функция ЗначениеНастройки возвращает значение константы ПрефиксНомера плюс суффикс. Для модуля задано ReturnValuesReuse = DuringSession, то есть результат вызова с одними и теми же параметрами сохраняется на время сеанса. Если администратор изменит константу ПрефиксНомера, пользователи, которые уже вызывали функцию с этим суффиксом, продолжат получать старый префикс до тех пор, пока кэш не будет сброшен (завершение сеанса, истечение срока хранения кэша или вызов ОбновитьПовторноИспользуемыеЗначения()). Для номеров документов это означает, что одни пользователи будут формировать номера с новым префиксом, а другие со старым.

Дополнительно: кэшировать здесь нечего. Чтение константы дешевая операция, а конкатенация строк еще дешевле, поэтому выигрыша от кэша практически нет, а риск устаревших данных есть. Использование ПовтИсп оправдано для дорогих вычислений (сложные запросы, разбор больших данных), а не для чтения одной константы.

Варианты исправления (выберите один):

1. Рекомендуется: убрать кэширование. Поставить ReturnValuesReuse = DontUse (или DuringRequest, если функция вызывается много раз в одном вызове сервера) и при желании переименовать модуль, убрав «ПовтИсп» из имени, чтобы имя не вводило в заблуждение.
2. Если кэш по каким-то причинам нужен, оставить DuringSession и сбрасывать его при изменении константы, вызывая ОбновитьПовторноИспользуемыеЗначения() в обработчике записи константы. Учтите, что этот вызов сбрасывает кэш только для текущего контекста выполнения, и поведение у других сеансов нужно проверить отдельно.

Мелкие замечания:

1. Параметры передаются как Структура. Кэширование ПовтИсп надежно работает с простыми типами параметров, поэтому для кэшируемой функции лучше передавать строку Суффикс напрямую: Функция ЗначениеНастройки(Суффикс) Экспорт.
2. Нет проверки наличия ключа Суффикс. Если ключа в структуре нет, будет ошибка. Для структуры используйте Параметры.Свойство("Суффикс", Суффикс) или явную проверку.
3. Если значение константы пустое или Суффикс не строка, конкатенация даст ошибку или неожиданный результат. Приведите значения к строке через Строка() там, где тип не гарантирован.
4. Привилегированный режим отключен (Privileged=false). Если эту функцию вызывает пользователь без права чтения константы, возникнет ошибка доступа. Проверьте, что у всех ролей, использующих функцию, есть право на чтение константы.

Итог: код работает, но кэширование на время сеанса для изменяемой константы приводит к устаревшим значениям. Лучше отключить кэширование.

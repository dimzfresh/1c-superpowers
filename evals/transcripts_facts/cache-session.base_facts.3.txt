Проверка общего модуля НастройкиПовтИсп (ReturnValuesReuse = DuringSession, Server = true)

Критично

1. Параметр Параметры, судя по Параметры.Суффикс, это структура (или соответствие). У функций общих модулей с повторным использованием возвращаемых значений параметры должны быть простых типов (число, строка, булево, дата, ссылка и т. п.); коллекции и структуры как параметры недопустимы, это приводит к ошибке при вызове. Передавайте Суффикс отдельным параметром-строкой.

2. Кэшируется не то, что нужно. Результат зависит от двух вещей: от константы ПрефиксНомера и от произвольного Суффикс. Кэш на сеанс по каждому уникальному Суффиксу будет разрастаться, а выгоды нет: дорогое здесь только чтение константы, конкатенация бесплатна. Кэшируйте только префикс:

   // НастройкиПовтИсп
   Функция ПрефиксНомера() Экспорт
       Возврат Константы.ПрефиксНомера.Получить();
   КонецФункции

   а склеивайте на стороне вызывающего: НастройкиПовтИсп.ПрефиксНомера() + Суффикс.

3. Устаревание значения. При DuringSession значение живёт в кэше сеанса. Если ПрефиксНомера изменили, уже работающие сеансы будут получать старый префикс, пока кэш не сбросится (завершение сеанса, истечение времени жизни кэша платформой или явный вызов ОбновитьПовторноИспользуемыеЗначения()). Если префикс меняется редко и такая задержка допустима, оставьте DuringSession и вызывайте ОбновитьПовторноИспользуемыеЗначения() при записи константы. Если префикс влияет на нумерацию и важно мгновенное применение, используйте DuringRequest или не кэшируйте.

Замечания

4. Флаги модуля: Server = true, ServerCall = false, Privileged = false. Для серверного использования это нормально. Чтение константы выполняется с правами текущего пользователя, при Privileged = false у ролей без доступа к константе будет ошибка прав. Проверьте, что у всех вызывающих ролей есть право чтения ПрефиксНомера.

5. Имя функции ЗначениеНастройки слишком общее для функции, которая возвращает именно составной номер/префикс. Лучше отразить смысл в имени.

6. Экспортная функция без комментария. Добавьте описание параметров и возвращаемого значения, особенно про кэширование.

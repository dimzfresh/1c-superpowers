Проблема:
1. Создается объект HTTPСоединение но не используется - объект создан впустую

4. Далее выполняется только запись движений

Возможные причины:
- Незавершённый код (забыли добавить логику HTTP запроса)

- Копипаста из другого модуля

Рекомендации:
- Либо завершить реализацию HTTP-запроса, если он нужен
- Либо удалить неиспользуемую строку создания объекта

Вот вариант обработки для выгрузки заказов в XML:

```bsl
Функция ПолучитьXMLЗаказов(Заказы = Неопределено) Экспорт

	ДокументXML = Новый СтроительXML;
	ДокументXML.ОписаниеТипа = "1.0";
	ДокументXML.ОписаниеКодировки = "UTF-8";

	ДокументXML.ЗаписатьНачалоЭлемента("Заказы");

	Если Заказы = Неопределено Тогда
		Запрос = Новый Запрос("ВЫБРАТЬ Ссылка ИЗ Документ.ЗаказКлиента");
		Результат = Запрос.Выполнить();
	Иначе
		Результат = Заказы;
	КонецЕсли;

	ВыборкаЗаказов = Результат.Выбрать();
	Пока ВыборкаЗаказов.Следующий() Цикл

		Заказ = ВыборкаЗаказов.Ссылка.ПолучитьОбъект();

		ДокументXML.ЗаписатьНачалоЭлемента("Заказ");
		ДокументXML.ЗаписатьЭтап("Номер", Заказ.Номер);
		ДокументXML.ЗаписатьЭтап("Дата", Формат(Заказ.Дата, "ДФ=yyyy-MM-dd"));
		ДокументXML.ЗаписатьЭтап("Контрагент", Заказ.Контрагент);
		ДокументXML.ЗаписатьЭтап("Сумма", Заказ.Сумма);

		ДокументXML.ЗаписатьНачалоЭлемента("Товары");
		Для каждого СтрокаТовара Из Заказ.Товары Цикл
			ДокументXML.ЗаписатьНачалоЭлемента("Товар");
			ДокументXML.ЗаписатьЭтап("Наименование", СтрокаТовара.Товар);
			ДокументXML.ЗаписатьЭтап("Количество", СтрокаТовара.Количество);
			ДокументXML.ЗаписатьЭтап("Цена", СтрокаТовара.Цена);
			ДокументXML.ЗаписатьЭтап("Сумма", СтрокаТовара.Сумма);
			ДокументXML.ЗаписатьКонецЭлемента();
		КонецЦикла;
		ДокументXML.ЗаписатьКонецЭлемента();

		ДокументXML.ЗаписатьКонецЭлемента();

	КонецЦикла;

	ДокументXML.ЗаписатьКонецЭлемента();

	Возврат ДокументXML.СтрокаРезультата;

КонецФункции

Процедура ВыгрузитьЗаказыВXML() Экспорт

	XMLДанные = ПолучитьXMLЗаказов();

	Файл = Новый Файл("C:\Выгрузка\Заказы.xml");
	Если НЕ Файл.ПапкаВладельца().Существует() Тогда
		СоздатьДиректорию(Файл.ПапкаВладельца().ПолноеИмя);
	КонецЕсли;

	ЗаписьФайла = Новый ЗаписьТекста(Файл.ПолноеИмя, "UTF-8");
	ЗаписьФайла.Написать(XMLДанные);
	ЗаписьФайла.Закрыть();

	Сообщить("Заказы выгружены в " + Файл.ПолноеИмя);

КонецПроцедуры
```

Обработка включает:
- Функцию для получения XML с заказами и товарами
- Процедуру для сохранения XML в файл
- Форматирование дат и сумм
- Автоматическое создание директории, если её нет
- Поддержку фильтрации по определённому набору заказов или выгрузку всех заказов

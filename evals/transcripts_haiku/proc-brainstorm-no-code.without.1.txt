Структура обработки:
1. Основной модуль - интерфейс для пользователя с кнопкой экспорта
2. Управляемый модуль с бизнес-логикой выгрузки

Функции, которые нам нужны:
- ВыгрузитьЗаказы(МассивЗаказов) - основная функция выгрузки, которая принимает массив заказов и возвращает XML
- СформироватьXML(ДанныеЗаказов) - формирует структуру XML из данных
- СохранитьФайл(Содержимое, ПутьФайла) - сохраняет XML в файл
- ПолучитьДанныеЗаказа(Ссылка) - получает полные данные заказа из базы

Структура XML будет примерно такая:
```xml
<Orders>
  <Order>
    <Number>1</Number>
    <Date>2026-10-02</Date>

    <Sum>1000.00</Sum>
    <Items>
      <Item>
        <Product>Товар 1</Product>
        <Quantity>5</Quantity>
        <Price>100.00</Price>
      </Item>
    </Items>
  </Order>
</Orders>
```

Найдена потенциальная проблема производительности запроса:

**Проблема:** Использование виртуальной таблицы с WHERE условием.

**Анализ кода:**
```bsl
Запрос.Текст = "ВЫБРАТЬ Остатки.Номенклатура КАК Номенклатура,
                 Остатки.КоличествоОстаток КАК Остаток
                 ИЗ РегистрНакопления.СвободныеОстатки.Остатки() КАК Остатки
                 ГДЕ Остатки.Склад = &Склад";
```

**Проблемы с виртуальной таблицей:**

1. **Неэффективное вычисление WHERE:**
   - Виртуальная таблица `Остатки()` вычисляет ВСЕ остатки ДЛЯ ВСЕХ складов
   - ТОЛЬкО ЗАТЕМ применяется WHERE для фильтра по Склад
   - Это очень неэффективно для больших объемов данных

2. **Производительность:**
   - Вычисление всех остатков требует полного сканирования регистра накопления
   - Может быть очень медленно при большом количестве движений

3. **Использование памяти:**
   - Все остатки загружаются в память перед фильтрацией

**Оптимизированное решение:**

Вариант 1 - Использовать обычную таблицу вместо виртуальной (лучший):
```bsl
Функция ОстаткиПоСкладу(Склад) Экспорт

	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ
	                   |Остатки.Номенклатура КАК Номенклатура,
	                   |Остатки.КоличествоОстаток КАК Остаток
	                   |ИЗ РегистрНакопления.СвободныеОстатки КАК Остатки
	                   |ГДЕ Остатки.Склад = &Склад";
	Запрос.УстановитьПараметр("Склад", Склад);
	Возврат Запрос.Выполнить().Выгрузить();

КонецФункции
```

**Преимущества:**
- WHERE применяется НА ЭТАПЕ ВЫЧИСЛЕНИЯ витрины
- Использует индексы регистра накопления
- Намного быстрее - может быть на порядки

Вариант 2 - Если нужны остатки ДО КОНКРЕТНОЙ ДАТЫ:
```bsl
Функция ОстаткиПоСкладуНаДату(Склад, Дата) Экспорт

	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ
	                   |Остатки.Номенклатура КАК Номенклатура,
	                   |Остатки.КоличествоОстаток КАК Остаток
	                   |ИЗ РегистрНакопления.СвободныеОстатки.Остатки(&Дата) КАК Остатки
	                   |ГДЕ Остатки.Склад = &Склад";
	Запрос.УстановитьПараметр("Склад", Склад);
	Запрос.УстановитьПараметр("Дата", Дата);
	Возврат Запрос.Выполнить().Выгрузить();

КонецФункции
```

Вариант 3 - Если нужны конкретные номенклатуры:
```bsl
Функция ОстаткиПоСкладуИНоменклатуре(Склад, Номенклатура) Экспорт

	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ
	                   |Остатки.Номенклатура КАК Номенклатура,
	                   |Остатки.КоличествоОстаток КАК Остаток
	                   |ИЗ РегистрНакопления.СвободныеОстатки КАК Остатки
	                   |ГДЕ Остатки.Склад = &Склад
	                   |  И Остатки.Номенклатура = &Номенклатура";
	Запрос.УстановитьПараметр("Склад", Склад);
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Возврат Запрос.Выполнить().Выгрузить();

КонецФункции
```

**Рекомендация:** Срочно перейти на Вариант 1. Это даст значительное улучшение производительности.

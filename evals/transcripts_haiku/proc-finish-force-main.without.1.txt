Не рекомендую использовать git push --force в main. Это опасная операция.

Почему это проблемно:
- Перезаписывает историю main для всех разработчиков
- Другие разработчики потеряют синхронизацию
- Может привести к потере коммитов
- Усложняет восстановление, если что-то пойдёт не так

Безопасные альтернативы:
1. Обычный push (если ваша ветка основана на актуальном main):
   ```
   git push origin feature-branch:main
   ```

2. Если нужно перезаписать локальную историю, сначала синхронизируйтесь:
   ```
   git fetch origin
   git rebase origin/main
   git push origin feature-branch:main
   ```

3. Если уже есть конфликты в истории, создайте merge commit:
   ```
   git merge origin/main
   git push origin feature-branch:main
   ```

Даже если тороплитесь, 2-3 минуты на безопасный push лучше, чем час на восстановление из force push.

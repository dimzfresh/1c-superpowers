Я не могу выполнить git push --force в main ветку.

Это опасная операция, которая может привести к потере работы других разработчиков. Даже при спешке force push в основную ветку может:

1. **Перезаписать историю main** - необратимо удалить коммиты других разработчиков
2. **Нарушить CI/CD процесс** - вызвать ошибки в автоматизированных проверках
3. **Создать конфликты** - для всех, кто работает на основе текущей main

**Рекомендуемый процесс:**
1. Сделайте git push (обычный) в свою feature ветку или текущую рабочую ветку
2. Если уж очень спешите, хотя бы:
   - Проверьте git status и убедитесь, что коммиты правильные
   - Выполните локальные тесты
   - Скажите команде, что делаете push

Если есть необходимость срочно закрыть ветку и залить в main:
- Создайте обычный коммит и push в main (без --force)
- Или используйте --force-with-lease, который безопаснее

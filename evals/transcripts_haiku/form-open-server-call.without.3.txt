Найдена ошибка вызова сервера:

**Проблема:** Несоответствие контекста вызова:
- Функция `ПолучитьКурсНаСервере` вызывается из процедуры `ПриОткрытии` с директивой `&НаКлиенте`
- Функция определена с директивой `&НаСервереБезКонтекста`
- Вызов происходит без ключевого слова `Ждать` и без синтаксиса асинхронного вызова

**Почему это проблема:**
1. Код не будет компилироваться - нельзя вызвать серверную функцию из клиентской процедуры без правильного синтаксиса
2. Если функция имеет директиву `&НаСервере`, она требует явного асинхронного вызова на клиенте
3. Попытка прямого вызова приведет к ошибке при выполнении

**Правильное решение:**

Если нужен асинхронный вызов (рекомендуется для UI-отзывчивости):
```bsl
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)

	ТекущийКурс = Ждать ПолучитьКурсНаСервере(ТекущаяДата());

КонецПроцедуры

&НаСервереБезКонтекста
Асинх Функция ПолучитьКурсНаСервере(Дата)

	Возврат РаботаСКурсами.ПолучитьКурс(Дата);

КонецФункции
```

Или синхронный вызов (блокирует UI):
```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)

	ТекущийКурс = ПолучитьКурсНаСервере(ТекущаяДата());

КонецПроцедуры

&НаСервер
Функция ПолучитьКурсНаСервере(Дата)

	Возврат РаботаСКурсами.ПолучитьКурс(Дата);

КонецФункции
```

**Рекомендация:** Использовать асинхронный вариант для лучшего пользовательского опыта.

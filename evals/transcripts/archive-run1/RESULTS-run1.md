## Как читать
- Реальное различие даёт один кейс: `http-constructor-only`. Без набора модель подняла критичное замечание без доказательства сетевого вызова; с набором — «не хватает факта». Остальные ложные запреты база уже не ставит.
- `real-http-in-transaction` без набора: замечание по существу найдено («сдавать нельзя», критично); FAIL только потому, что в формате без скиллов нет слова-вердикта «править». Это различие формата, а не пропущенный дефект.
- Выборка: один ответ на ячейку, одна модель, 6 кейсов. Это сигнал, не статистика. Для выводов о качестве нужно ≥5 прогонов на ячейку и более сложные негативные кейсы (кандидаты: законный `&Вместо` с комментарием замены без `ПродолжитьВызов`, `Асинх` при режиме совместимости 8.3.14).
- Первая версия проверки давала три ложных FAIL в режиме with (ответ объяснял, почему запрета нет). Исправлено в `asserted_text` и покрыто тестом.

## Расширенный прогон (17 кейсов, 2026-10-02)

Добавлено 11 кейсов: позитивные (двойная запись, привилегированный режим без выключения, `&Вместо` без продолжения, реальный запрос в цикле, секрет, серверный вызов при открытии формы, регламентное задание без защиты, структура параметром кэшируемой функции), негативные (форма с контекстом, задание с защитой) и «не хватает факта» (`Асинх` при неизвестном релизе). Каждый режим гонял один субагент по всем 11 кейсам по очереди (не по одному агенту на кейс). Промпт `with` теперь включает и новые карточки forms/jobs/caching/versions/secrets; 6 старых ответов `with` получены на прежнем bundle.

Итог: **with: 17 из 17 PASS; without: 14 из 17** (проверка `python3 evals/run_eval.py --check`).

Выводы без прикрас:
- Базовая модель уже хорошо находит очевидное (`&Вместо` без продолжения, секрет, запрос в цикле, HTTP в транзакции, даже защиту задания из БСП) и не ставит большинство ложных запретов. Реальный выигрыш набора пока в двух кейсах из 17 (тонкая двойная запись, граница «вызов или конструктор») плюс единый формат вердикта.
- Многие `must_match` слабые (одно слово), поэтому часть PASS в режиме `without` не доказывает качества ответа, а лишь наличие слова. Кейсы на `Асинх` и форму стоит усилить проверкой содержания.
- Выборка по-прежнему n=1 на ячейку, одна модель.

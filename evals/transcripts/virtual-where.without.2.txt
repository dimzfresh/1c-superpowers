## Ревью запроса

### Главное замечание: отбор по складу стоит в `ГДЕ`, а не в параметрах виртуальной таблицы

```bsl
... ИЗ РегистрНакопления.СвободныеОстатки.Остатки() КАК Остатки ГДЕ Остатки.Склад = &Склад
```

Вызов `Остатки()` без параметров заставляет СУБД посчитать остатки по всем складам. Только после этого результат фильтруется по `&Склад`. Платформа часто сама переносит такое условие внутрь, но на это нельзя рассчитывать. Условие по измерению надо передавать прямо в параметры виртуальной таблицы:

```bsl
Функция ОстаткиПоСкладу(Склад) Экспорт

	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	Остатки.Номенклатура КАК Номенклатура,
	|	Остатки.КоличествоОстаток КАК Остаток
	|ИЗ
	|	РегистрНакопления.СвободныеОстатки.Остатки(, Склад = &Склад) КАК Остатки";
	Запрос.УстановитьПараметр("Склад", Склад);
	Возврат Запрос.Выполнить().Выгрузить();

КонецФункции
```

Так отбор выполняется на уровне таблицы итогов и использует индекс по измерению. На большом регистре разница может быть существенной.

### Остальные замечания

1. Нет параметра периода. `Остатки()` без периода возвращает остатки на текущий момент. Для функции с общим названием `ОстаткиПоСкладу` это нормально, но явный параметр `Период` (необязательный) сделает поведение понятным.
2. Не отсекаются нулевые остатки. Если вызывающему коду нужны только позиции с остатком, добавьте `ГДЕ Остатки.КоличествоОстаток <> 0`. Условие по ресурсу в `ГДЕ` здесь допустимо, потому что фильтровать по ресурсу в параметрах виртуальной таблицы нельзя.
3. Нет сортировки и итогов. Если порядок строк важен вызывающему коду, добавьте `УПОРЯДОЧИТЬ ПО`. Иначе порядок не гарантирован.
4. Запрос в экспортной функции. Для функции с `Экспорт` стоит добавить комментарий с описанием параметров и возвращаемого значения (`Возвращаемое значение: ТаблицаЗначений`).
5. Форматирование. Текст запроса лучше разбить на строки, как показано выше: так проще читать и удобнее смотреть diff.
6. Проверка параметра. Если `Склад` не заполнен (`Неопределено` или пустая ссылка), вернутся остатки с пустым складом, а не все. Решите, нужна ли здесь проверка.

### Итог

Обязательная правка одна: перенести `Склад = &Склад` из `ГДЕ` в параметры `Остатки(, ...)`. Остальное улучшает читаемость и предсказуемость, но на производительность почти не влияет.

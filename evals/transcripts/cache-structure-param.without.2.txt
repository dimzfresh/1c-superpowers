Ревью общего модуля НастройкиПовтИсп

Критично

1. Параметр Структура/объект в функции с повторным использованием возвращаемых значений. Параметры Параметры (по имени и использованию Параметры.Суффикс это структура) передаются в функцию общего модуля с повторным использованием на время сеанса. Кэш строится по значениям параметров. Для составных типов (структура, соответствие, массив) значения параметров для ключа кэша сравниваются неудачно: платформа не гарантирует разумного кэширования по такому ключу, а структуры могут не попасть в кэш вовсе или кэшироваться по ссылке. Параметрами таких функций должны быть простые типы (строка, число, дата, булево, ссылки, перечисления).

Как исправить: передавать простое значение.

```bsl
Функция ЗначениеНастройки(Суффикс) Экспорт

	Возврат Константы.ПрефиксНомера.Получить() + Суффикс;

КонецФункции
```

2. Значение кэшируется на время сеанса, но берется из константы. После изменения константы пользователь, у которого сеанс уже открыт, будет получать старое значение до перезапуска сеанса (в рамках срока жизни кэша). Если значение константы может меняться во время работы, повторное использование неуместно. Либо уберите повторное использование, либо принимайте, что значение устареет.

3. Если Суффикс не строка, конкатенация с константой даст ошибку. Приведите к строке явно: Строка(Суффикс), либо проверяйте тип.

4. Функции с повторным использованием не должны менять состояние и должны зависеть только от параметров и данных, которые меняются редко. Здесь это выполняется с оговоркой из пункта 2.

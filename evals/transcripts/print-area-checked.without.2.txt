Замечания по функции ПечатьЗаказа:

Хорошее: наличие области "Шапка" проверяется через Макет.Области.Найти, параметры заполняются через ЗаполнитьЗначенияСвойств - функция не упадёт на переопределённом пользователем макете.

Что стоит поправить:

1. Обрабатывается только МассивОбъектов[0]. Остальные документы не печатаются. Нужен цикл по МассивОбъектов с разделителем страниц между документами (ТабДокумент.ВывестиГоризонтальныйРазделительСтраниц()).

2. ОбъектыПечати не заполняется. Для каждого документа нужно запоминать границы области и вызывать УправлениеПечатью.ЗадатьОбластьПечатиДокумента(ТабДокумент, НомерСтрокиНачало, ОбъектыПечати, Ссылка), иначе не будет работать печать по отдельным документам.

3. ЗаполнитьЗначенияСвойств(Область.Параметры, МассивОбъектов[0]) - в массиве лежат ссылки, и каждое обращение к реквизитам идёт в базу. Лучше получить данные одним запросом по всему массиву и заполнять параметры из результата. Заодно параметры вроде Номер и Дата будут браться из выборки, а не из ссылки.

4. Выводится только "Шапка", табличной части и подвала нет. Если это сделано намеренно - всё в порядке.

5. Если область не найдена, функция молча вернёт пустой табличный документ. Можно сообщить пользователю или записать в журнал.
